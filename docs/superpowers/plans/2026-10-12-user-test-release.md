# Подготовка LRT к тесту пользователями

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Track completed work below.

**Goal:** Подготовить чистый серверный стенд с реальными городами и кофейнями и исправить препятствия в основных пользовательских сценариях.

**Architecture:** API и интерфейс остаются в существующем Docker Compose. Одноразовая очистка выполняется отдельно от запуска и миграций: сохраняет указанного администратора и конфигурацию, заменяет операционные данные справочником, ставит постоянный маркер. Перед очисткой Ubuntu-скрипт останавливает запись и создаёт проверяемый backup.

**Tech Stack:** NestJS, Prisma, PostgreSQL 17, React, Vite, Docker Compose, Nginx.

**Spec:** [Порядок подготовки](../../uat/user-test-release.md); требования пользователя от 12 октября 2026 года.

## Review Focus

- Некорректный список, отсутствующий ADMIN или повторный запуск должны завершаться до удаления данных.
- Очистка должна откатываться целиком при ошибке и учитывать ограничения внешних ключей.
- Лидер без назначений видит понятное пустое состояние; ошибка загрузки не выглядит как пустая база.
- Архивирование метрик/вопросов не блокирует автосохранение и не меняет исторические ответы.
- Выход, вход с другим регистром почты, клавиатурное управление и мобильная навигация работают.
